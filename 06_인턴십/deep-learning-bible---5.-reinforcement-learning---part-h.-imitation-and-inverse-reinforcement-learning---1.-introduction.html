Deep Learning Bible - 5. Reinforcement Learning - Part H. Imitation and Inverse Reinforcement Learning - 1. Introduction

Deep Learning Bible - 5. Reinforcement Learning - Part H. Imitation and Inverse Reinforcement Learning - 1. Introduction

2026년 9월 01일10 min read

  • ImitationLearning
  • ReinforcementLearning
  • Lecture
  • Imitation Learning의 목적은 전문가의 행동을 모방함으로써 원하는 행동을 효율적으로 학습하는 것
  • 로봇 시스템은, 시연된 동작을 모방해 주어진 Task를 실행하기 위한 Policy를 학습함

Imitation Learning의 성공 사례

  • ALVINN

    • 신경망이 차량을 운전하기 위해 image를 discrete action에 mapping하는 방법을 학습함

  • Kendama

    • 줍기, 움직이기, 놓기 등 사람 시연에서 high-level Task를 가르치려고 함
    • low-level Task 수준에선, path planning을 수행함

  • Deep Learning의 발전으로 대량의 사람 시연 data에서 Action pattern 학습이 가능해짐

Robotics에서 본 Imitation Learning

  • 전문가의 시연을 기반으로 원하는 Action을 재현하는 방법의 한 분류

    • 인간에서 로봇 시스템으로 기술을 전송하는 기술

  • 핵심

    • 일반적인 관점
      • Imitation Learning의 사용 이유와 시기
      • 시연자 선택
      • 전문가의 시연 데이터 기록 방법
      • 모방할 내용 선택
    • 알고리즘 관점
      • policy 표현 방법
      • policy train 방법

  • 다양한 설계 선택

    • 1) RC 헬리콥터
      • 전문가의 시연을 통해, 곡예 비행을 학습함
    • 2) 수술 로봇
      • 전문가의 시연을 통해, 매듭 묶기 궤적을 학습함
    • 3) 사족 보행 로봇
      • Reward, Cost Function을 학습해 다른 지형에 대한 일반화 능력을 학습함

  • Imitation Learning을 적용하기 위해선, 구조를 파악하고 문제를 공식화하며, 효율적인 알고리즘을 설계하는 것이 필수적임

Imitation Learning과 Supervised Learning의 차이점

  • 구조적 제약

    • joint, 문제에 대한 한계⋅dynamics⋅stability 등을 만족하면서 여러 단계의 Action이 일관되게 이어져야 함

  • 입력 분포 변화

    • 어떤 Action을 수행하는지에 따라, 이후 받게 될 입력 data 분포가 달라짐

  • Demonstrator와 Learner의 구현이 다른 경우

    • Learner : train되고 있는 Policy. 즉, 신경망
    • 시연된 동작을 로봇이 실행할 수 있게 조정해야 함

  • Domain Adaptation (Covariate Shift)

    • Covariate : 공변량. 모델 예측에 사용되는 input 변수 X

    • Source Domain과 Goal Domain의 Distribution이 상이

      • Source Domain : 전문가의 시연
      • Goal Domain : Learner의 재현

    • 많은 비용이 필요하므로, Demo Dataset은 모든 상황을 포괄하지 않음
      → Learner는 Demonstration에 없는 상태를 접하게 됨

  • RL과 밀접한 관련이 있음

    • 원하는 Actionn을 장려하는 Reward Function을 사용함
    • 그러나, Imitation Learning에선 최적의 시연을 가정해 RL에서 사용할 수 없는 효율적인 방법을 가능하게 하는 사전 지식을 제공함
      • Imitation Learning을 통해 Task를 train할 때, sample complexity가 크게 감소했음
        • Sample Complexity : 원하는 성능이나 Accuracy 도달을 위해 필요한 sample 수

Machine Learning & Robotics 연구를 위한 통찰

  • Imitation Learning은 Action을 보여주는 것으로, Robot의 Action을 프로그래밍할 수 있는 직관적인 방법을 제공하므로 큰 관심을 끌었음

  • 로봇 시스템에서 trajectory를 계획할 때, 몇 가지 제약 조건을 만족해야 할 필요가 있음

    • Robot Application에 필요한 제약 조건을 충족하는 맞춤형 trajectory를 개발함
      • Robot Application : 로봇을 이용해 수행하려는 구체적인 Task나 사용 사례
    • 그러나, 항상 로봇용 맞춤 policy 등을 직접 설계할 필요는 없음

  • ML 방법을 Imitation Learning과 Robot Application에 적용하는 것은 어려움

    • Imitation Learning에선 시연 data 수집과 rollout에 많은 비용과 시간이 소요됨
      • Rollout : State-Action이 순서대로 이어지는 trajectory를 생성하는 과정.
        한 Episode 동안 policy를 구동하는 것

  • Markov Property

    • Markov Property
      • 미래 State가 현재 State에만 의존하며, 과거 State에는 의존하지 않는 경우

        • 즉, 과거의 필요한 정보가 현재 State에 이미 반영되어 있다고 가정하는 것

        • 다음 State xt+1​이 현재 State xt​에만 의존하는 경우

        • State sequence x0​,...xt​가 어느 timestep t에서 미래 State xt+1​,xt+2​,...가 현재 State xt​를 통해서만 과거 x0​,...xt​에 의존하는 경우

    • Markov Chain
      • Markov Property를 만족하며 진행되는 Stochastic State Sequence

  • Markov Decision Process (MDP)

    • Markov Property를 만족하는 과정

    • 6개의 요소를 묶은 tuple로 정의

      • X : State Space
      • U : Action⋅Control Input Space
      • P : Transition Probability. (xt​,ut​)에서 다음 State (xt+1​)로 전이될 확률
        • Action을 수행했을 때, 다음 State가 어떻게 변할지 확률로 나타내는 함수
      • τ : 미래 Reward 중요도 계산 Discount Factor
      • D : Initial State Distribution
      • R : Reward Function

    • Finite MDP

      • State Space와 Action Space가 유한한 경우

  • Entropy

    • H(p)=−∫p(x)lnp(x)dx

      • x : 확률 변수
      • p(x) : 확률 분포
      1. 불확실성 측정
        • Entropy가 높으면, 불확실성이 큼
      2. Information Theory
        • 확률 변수가 가진 불확실성과 정보를 수학적으로 측정하는 이론
        • 결과를 예측하기 어려울수록, 더 높은 Entropy를 가짐
      3. Uniform Distribution
        • 가능한 모든 사건의 확률이 동일함
          → 최대 Entropy

  • Kullback-Leibler (KL) 발산

    • 두 Distribution 간 차이를 식별하는데 사용됨

      • Stochastic Policy를 train하거나, Deterministic Policy에서 Stochastic Trajectory이 발생하는 경우에 유용함
        • Stochastic Trajectory : 초기 상태와 동일한 Policy에서도 환경이나 Action 때문에 매번 다른 Trajectory가 생성되는 경우

    • 비대칭적임

      • p를 기준으로 q와 비교한 것과 q를 기준으로 p를 비교한 것이 다름
      • DKL​(p∣∣q)=DKL​(q∣∣p)

    • DKL​(p(x)∥q(x))=∈p(x)lnq(x)p(x)​dx
      | 참고 : KL Divergence

  • Information & Moment Projections

    • Dataset에서 Policy를 train하는 방식 중 하나는, Dataset을 Policy 함수 공간에 Projection

    1. Information Projection

      • p∗=pargmin​DKL​(p∥q)
        • 단일 mode에 집중
          • mode : 확률 밀도 또는 확률값이 가장 높은 지점. 봉우리

    2. Moment Projection

      • p∗=pargmin​DKL​(q∥p)
      • 여러 mode에 대해 평균을 구함

  • Maximum Entropy

    • 미지의 분포 q의 특징과 일치하는 Distribution p(x)를 선택하고자 함

    • Ep​[ϕ(x)]=Eq​[ϕ(x)]

      • q(x) : 형태를 알 수 없는 Unknown Distribution

      • ϕ(x) : feature function

      • Eq​[ϕ(x)] : 예상 값

      • 고유한 해를 찾기 위해서, The Maximum Entropy Principal 개념이 등장함

    • The Maximum Entropy Principal

      • 모든 Distribution 중에서 Entropy가 가장 큰 Distribution을 선택하자
        → Ep​[ϕ(x)]=Eq​[ϕ(x)]를 만족하는 가장 랜덤성이 큰 Distribution을 찾아야 함
        • H(p)=−∫p(x)lnp(x)dx
          • 해당 식이 최대가 되는 Distribution을 찾음
          • 이에 대해 Lagrange Multiplier를 적용함
            → p(x)∝exp(wTϕ(x))
            • Lagrange Multiplier (라그랑주 승수법) : 제약 조건이 있는 최적화 문제를 바꿔 푸는 방법

Imitation Learning Task Formulation

  • Imitation Learning의 목적은 Expert가 보여주는 Action 수행 방법을 모방하도록 Policy를 train하는 것

  • Demo는 다양한 조건 하에서 기록됨

    • s (Context Vector)
      • Task Condition
        • 로봇 시스템 초기 State나, 목표 물체 위치 등 Task와 관련된 모든 정보 포함
        • 현재 Task를 설명하므로, 실행 중 고정
        • State feature ϕt​가 유일한 변수
      • Trajectory와 함께 저장됨
    • r (Reward Signal)
      • 현재 State⋅Action이 Task 수행에 얼마나 좋은지 나타내는 reward 값
      • Expert의 Action Data와 함께 활용될 수 있음

  • Demo Dataset

    • D=(τ,s,r)
    • 수집한 Demonsartion Dataset D를 사용해, Expert와 Learner의 Feature Distribution 차이가 최소가 되도록 Policy π를 최적화함
      • π∗=argπmin​D(q(ϕ),p(ϕ))
