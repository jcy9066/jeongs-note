Action (ROS)

2026년 9월 01일1 min read

  • ROS

Action

  • 시간이 소요되는 작업을 요청하고, 진행 상황을 받으며, 필요 시 취소할 수 있는 비동기 통신 방식

    • Action Client

      • 작업을 Request하는 node
      1. Goal 전송 (목표 지정)
        ex) 로봇에게 특정 위치까지 이동 요청
      2. Goal 수락 여부 확인
      3. 실행 중 Feedback 수신
        ex) 이동 중 현재 진행률 전달
      4. Result 수신 후 필요 시 Cancel
        ex) 도착 후 성공/실패 결과

    • Action Server

      • 작업을 수행하는 node
      1. Goal 수신
      2. Goal 수락/거절
      3. 작업 수행
      4. 중간 Feedback 전송
      5. Result 전송 및 Cancel 처리

      • Goal과 Result는 Service
      • Feedback은 Topic

    • 파일 구조 ```
      Goal

      Result

      Feedback```

Action 목표 지정

  • ros2 action send_goal {action_name} {action_type} {goal_values}
