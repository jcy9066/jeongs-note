Transformation

  • 어떤 점, Vector, 좌표 등을 다른 위치⋅방향⋅크기 또는 좌표계 표현으로 바꾸는 연산

    • y=T(x)

      • x : 변환 전 값
      • T : Transformation
      • y : 변환 후 값

    • Translation, Rotation, Scaling, Shear, Projection을 포함하는 개념

Scaling

  • 좌표의 각 Axis 값을 일정 배율로 늘리거나 줄여 크기를 변화시키는 변환

Shear

  • 한 Axis의 좌표에 다른 Axis의 값을 더해 물체를 특정 방향으로 기울이는 변환

Rotation

  • 원점을 기준으로 Vector나 물체의 방향을 일정 각도만큼 회전시키는 변환

Permutation

  • Vector나 좌표의 성분 순서를 서로 바꾸는 변환

Affine Transformation

  • Linear Tranasformation에 translation을 추가한 변환

    • y=Ax+b

      • x : 변환 전 Vector
      • A : Linear Transfomation Matrix
      • b : Translation Vector
      • y : 변환 후 Vector

    • Translation

      • 점이나 물체의 위치만 일정한 방향과 거리만큼 이동시키는 변환. 즉, 평행이동
      • Non-Linear Transformation
        • 원점의 위치가 변경로
      • x′=x+t
        • t : Translation Vector

  • 범위 Transformation └─ Affine Transformation ├─ Linear Transformation │ ├─ Rotation │ ├─ Scaling │ ├─ Shear │ └─ Permutation │ └─ Translation

  • 특징

    • 유지되는 것

      • 직선은 변환 후에도 직선
      • 평행한 선은 변환 후에도 평행
      • 선분 위 점들의 상대적인 비율은 유지

    • 유지되지 않을 수 있는 것

      • 길이
      • 각도
      • 면적

TF (Transformation)

  • 로봇 상의 다수의 서로 다른 3D Coordinate Frames를 추적할 수 있도록 하는 package

    로봇 내 수 많은 3D Coorindate Frames

    • 각 frames는 시간에 따라 변화하고, tf는 이를 추적해 각 frame들 간의 상대적인 위치를 기록함

    • 서로 다른 좌표계에서 표현된 값을, 원하는 공통 좌표계로 변환하는 것

    • ROS2

      • /tf : 계속 변하는 transform
      • /tf_static : 고정된 transform

    • SLAM⋅Nav2

      • base_link : 로봇 본체 기준 좌표계
      • odom : odometry 기준 좌표계
      • map : 전역 좌표계

TF tree

  • 서로 다른 Coordinate Frame 간 translation 및 rotation 측면에서 offset을 추상적인 수준으로 정의함
