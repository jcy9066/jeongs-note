Context

  • Agent가 현재 판단할 때 참고할 수 있는 모든 정보

    • Context Window : LLM이 한 번에 처리할 수 있는 Context의 최대 크기

    • Context 효율 비교

      1. Skills
        • 매우 낮음
          • 평소에는 name + description만 로딩
          • 전체 프롬프트는 호출될 때 로딩
            • Context 친화적
        • 사용하지 않을 때 가장 가벼움
      2. Sub-Agent
        • 중간
          • 시작부터 description 로딩
        • 실행 시 별도의 Context 사용
        • 실행 중 가장 효율적
      3. MCP
        • 매우 높음
          • 모든 도구 설명이 매 로딩에 포함
